# United Kingdom Road Accident Analysis
This analysis utilizes a Kaggle dataset which explores road accidents in several districts in the UK, capturing vehicular, environmental and road-related conditions at the time of the accident. The programming language used is Python with various libraries including Pandas, Numpy, Matplotlib, Seaborn and Plotly. The GUI is developed using Tkinter to interact with the data visualization. The dataset can be found on kaggle: https://www.kaggle.com/datasets/atharvasoundankar/road-accidents-dataset s
